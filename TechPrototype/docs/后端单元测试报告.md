## 4. 本次重点补测范围

本次在原测试基础上补充了以下模块的正常流程、异常流程和边界条件：

- 认证与安全：注册、登录失败计数、旧 SHA-256 密码迁移、刷新令牌轮换、密码重置、JWT 生成/校验、认证过滤器、Redis 缓存及 CORS 配置。
- Agent：会话查询与删除、患者/照护者上下文、动作确认与执行、动作参数校验、意图解析、流式响应、长期记忆、GMS 记忆、Web 搜索和工具载荷转换。
- 健康业务：健康记录增删查、汇总与趋势、用户档案、健康目标、用户设置、设备同步、风险分析、健康事件处理。
- 家庭与急救：家庭绑定和权限、紧急联系人、SOS 事件、投递结果聚合、附近医院坐标转换与查询降级。
- 提醒与报告：一次性/每日/每周提醒、完成状态、幂等创建、周报缓存及各类健康指标平均值。
- 公共层：控制器接口面、DTO/VO/实体契约、全局异常映射及小型服务。

## 5. 代表性边界与异常场景

- 无效、过期、篡改和缺少用户声明的 JWT。
- 登录失败次数达到上限、损坏的 Redis 计数和旧密码哈希自动升级。
- Agent 动作越权、过期、取消、重复确认、工具失败和非法健康数据。
- 血压、血糖、心率、体重、经纬度、提醒时间及星期值的上下界。
- SOS 请求字段不完整、投递状态非法、终态回退、重复事件和重复联系人。
- 地图/GMS/大模型不可用、错误响应、无效 JSON 和空结果的安全降级。
- 缓存命中、未命中、损坏数据删除及序列化失败。
